# Distributed OTC Derivatives Pricing and Risk Analysis Platform

A Python-based distributed computing project that simulates the architecture of modern quantitative finance systems used for pricing OTC (Over-the-Counter) derivatives and performing risk analysis.

The platform aims to demonstrate core distributed systems concepts such as client-server communication, multithreading, logical clock synchronization, leader election, replication, load balancing, fault tolerance, and parallel computing. It also incorporates MPI for Monte Carlo simulations and Apache Spark for processing historical market data and analytics.

This repository is currently under active development as part of a Distributed Computing course and will be expanded incrementally throughout the project lifecycle.
